📡 API Overview

🌐

Base URL

https://your-site.netlify.app/api/

All endpoints are relative to this base URL. Replace with your deployed Netlify site URL.

🔒

Authentication

Some endpoints require authentication via Bearer token. Obtain token from POST /api/auth.

Include in headers: Authorization: Bearer <token>

⏱️

Rate Limits

Each endpoint has specific rate limits to prevent abuse. 429 responses include a Retry-After header.

📝 POST /api/register

Registers a server with the cloud relay. Called by the controlled computer when it starts up.

Rate Limit

10 requests per minute per IP

Request Headers

Content-Type: application/json

Request Body

{
    "server_id": "office-pc-123",     // Required, unique identifier (max 255 chars, alphanumeric + _ -)
    "name": "Office Desktop",         // Optional, display name (max 100 chars)
    "port": 5000                      // Optional, server port (default: 5000, range 1-65535)
}

Response (200 OK)

{
    "status": "registered",
    "server_id": "office-pc-123",
    "registered_at": "2024-01-15T10:30:00Z",
    "message": "Server registered successfully"
}

Error Responses

能able 全Status CodeDescription 400Validation failed (missing server_id, invalid format) 409Conflict (server already registered and active) 413Request too large (max 10KB) 415Unsupported media type (must be application/json) 429Too many requests (rate limit exceeded) 500Internal server error 点able

🔐 POST /api/auth

Authenticates a user and returns a session token for admin operations.

Rate Limit

5 requests per 15 minutes per IP (very strict to prevent brute force)

Request Body

    "password": "your_password"   // Required, password
}

Response (200 OK)

{
    "status": "authenticated",
    "token": "a1b2c3d4e5f67890abcdef1234567890abcdef1234567890abcdef12345678",
    "expires_at": "2024-01-15T11:30:00Z",
    "token_type": "Bearer"
}

Error Responses

🔄 Relay Endpoints (WebSocket-like)

These endpoints provide a WebSocket-like relay using HTTP long-polling. Used when direct connections fail.

POST /api/relay/create

Creates a new relay session.

# Request
POST /api/relay/create
Content-Type: application/json

{
    "server_id": "office-pc-123",
    "connection_token": "abc123..."
}

# Response
{
    "status": "relay_ready",
    "session_id": "relay-session-456"
}

GET /api/relay/stream/:session_id

Long-polling endpoint. Stays open up to 30 seconds, returns when data arrives.

# Request (long-poll, stays open)
GET /api/relay/stream/relay-session-456?role=controller

# Response when data available
{
    "type": "data",
    "payload": "base64_encoded_data",
    "timestamp": "2024-01-15T10:30:00Z"
}

# Response when no data (204 No Content)
# (client should immediately reconnect)

POST /api/relay/send/:session_id

Sends data through the relay to the other party.

# Request
POST /api/relay/send/relay-session-456
Content-Type: application/json

{
    "role": "controller",
    "data_base64": "base64_encoded_data"
}

# Response
{
    "status": "forwarded"
}

DELETE /api/relay/close/:session_id

Closes a relay session and cleans up resources.

# Request
DELETE /api/relay/close/relay-session-456

# Response
{
    "status": "closed"
}

🧪 Testing the API

You can test the API using curl commands:

# Check service status
curl https://your-site.netlify.app/api/status

# Register a test server
curl -X POST https://your-site.netlify.app/api/register \
  -H "Content-Type: application/json" \
  -d '{"server_id":"test-001","name":"Test Server","port":5000}'

# List servers
curl https://your-site.netlify.app/api/servers

# Send heartbeat
curl -X POST https://your-site.netlify.app/api/heartbeat/test-001

# Request connection
curl -X POST https://your-site.netlify.app/api/connect \
  -H "Content-Type: application/json" \
  -d '{"server_id":"test-001"}'

# Authenticate (admin)
curl -X POST https://your-site.netlify.app/api/auth \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"your_password"}'

# Delete a server (requires admin token)
curl -X DELETE https://your-site.netlify.app/api/delete/test-001 \
  -H "Authorization: Bearer <your_token>"
