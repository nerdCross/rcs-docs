🔒 Enterprise Security

🔐

End-to-End Encryption

All traffic is encrypted with Fernet (AES-128 in CBC mode with HMAC-SHA256) and TLS 1.2/1.3 with Perfect Forward Secrecy.

  • Machine-specific key derivation (PBKDF2, 100,000 iterations)
  • Perfect Forward Secrecy via ephemeral session keys
  • Certificate validation via certifi (trusted CA bundle)
🛡️

7 Layers of Defense

Defense in depth with multiple overlapping security controls:

  • Network Security - HTTPS only, IP whitelisting
  • Rate Limiting - Per-endpoint limits, IP blocking
  • Authentication - SHA256 with salt, constant-time comparison
  • Authorization - RBAC, granular permissions
  • Input Validation - SQL injection, XSS prevention
  • Audit & Monitoring - Complete audit trail
  • Integrity - SHA256 checksums, isolated environment
👤

Granular Permissions

Role-Based Access Control with fine-grained permissions:

  • Keyboard control
  • Mouse control
  • Screen viewing
  • File transfer
  • System commands
  • User management
  • Audit log access
📊

Complete Audit Trail

Every action is logged for compliance and forensic investigation:

  • All login attempts (success/failure)
  • All commands executed
  • All file transfers
  • All configuration changes
  • Exportable JSON reports

🌐 Network & Connectivity

🎯

3-Layer NAT Traversal

Guaranteed connectivity on ANY network configuration:

  • UDP Hole Punching - 5-20ms latency, 70-95% success rate
  • TCP Hole Punching - 10-30ms latency, 85-98% success rate
  • Relay Proxy - 50-200ms latency, 100% success rate

Auto-Discovery

Servers broadcast their presence automatically. No manual IP configuration needed.

  • UDP broadcast on port 5001 (every 5 seconds)
  • Client listening for discovery packets
  • Automatic server listing
  • No configuration required

Cloud Relay

Optional Netlify deployment for internet access when direct connections fail.

  • Free tier: 125k requests/month
  • 8 storage backends (GitHub Gist, Supabase, Redis, etc.)
  • Automatic server registration
  • Heartbeat monitoring (30-second intervals)

  • Direct - Connect to specific IP

📦 Deployment & Portability

🐍

Embedded Python

Self-contained Python 3.11.8 environment. No system Python required.

  • No administrator rights needed (client)
  • No system PATH modifications
  • No registry changes
  • Multiple versions can coexist
💿

Portable USB Mode

Run directly from USB drive without installation.

  • Extract to USB drive
  • Run from any computer
  • No traces left behind
  • Perfect for IT support
🪟

Windows Service

Server runs as Windows service with auto-start on boot.

  • Automatic startup
  • Auto-restart on crash
  • Event log integration
  • No user login required
🐧

Cross-Platform

Works on Windows, Linux, and macOS.

  • Windows: win32api, pyautogui
  • Linux: xdotool, scrot
  • macOS: Quartz, screencapture
  • Native performance on all platforms
