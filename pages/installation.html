Manual Install (Advanced)

# Extract package
Expand-Archive RemoteControl_Server_v2.0.0.zip -DestinationPath C:\Temp\ServerInstall

# Run installer
cd C:\Temp\ServerInstall
.\install_server.ps1

# Configure firewall (optional)
netsh advfirewall firewall add rule name="Remote Control Server" dir=in action=allow protocol=TCP localport=5000

# Register Windows service (optional)
.\remote_service.ps1 -Mode install
4

Verify Installation

# Check service status
Get-Service RemoteControlServer

# Check firewall rule
netsh advfirewall show rule name="Remote Control Server"

# Check if port is listening
netstat -an | findstr :5000

Run as Systemd Service (Optional)

# Create service file
sudo nano /etc/systemd/system/remotecontrol.service

# Add content:
[Unit]
Description=Remote Control Server
After=network.target

[Service]
Type=simple
User=$USER
WorkingDirectory=/home/$USER/RemoteControlSystem
ExecStart=/usr/bin/python3 server_app.py
Restart=always

[Install]
WantedBy=multi-user.target

# Enable and start service
sudo systemctl enable remotecontrol
sudo systemctl start remotecontrol
sudo systemctl status remotecontrol

Grant Screen Recording Permission

macOS requires explicit permission for screen capture. Follow these steps:

  1. Open System Settings → Privacy & Security
  2. Select Screen Recording
  3. Click the + button and add your terminal app (Terminal, iTerm2, or your IDE)
  4. Toggle the switch to enable permission
  5. Restart the terminal application
⚠️ Important: Without screen recording permission, the screen capture feature will not work!

Grant Accessibility Permission

For keyboard and mouse control, grant accessibility permission:

  1. Open System Settings → Privacy & Security
  2. Select Accessibility
  3. Click the + button and add your terminal app
  4. Enable the toggle for your terminal app
⚠️ Important: Without accessibility permission, keyboard and mouse control will not work!

Run as LaunchDaemon (Optional - Auto-start on Login)

# Create LaunchAgents plist file
nano ~/Library/LaunchAgents/com.remotecontrol.server.plist

# Add content:
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.remotecontrol.server</string>
    <key>ProgramArguments</key>
    <array>
        <string>/usr/local/bin/python3</string>
        <string>/Users/$USER/RemoteControlSystem/server_app.py</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
</dict>
</plist>

# Load the service
launchctl load ~/Library/LaunchAgents/com.remotecontrol.server.plist

# Check if running
launchctl list | grep remotecontrol

🔧 Troubleshooting

Windows Issues

  • Service won't start: Check logs at `C:\Program Files\RemoteControlServer\logs\server.log`
  • Firewall blocking: Run `netsh advfirewall firewall add rule name="Remote Control Server" dir=in action=allow protocol=TCP localport=5000`
  • Port in use: Change port in server_config.json
  • Permission denied: Run PowerShell as Administrator

Linux Issues

  • xdotool not found: `sudo apt install xdotool` (Ubuntu) or `sudo dnf install xdotool` (Fedora)
  • scrot not found: `sudo apt install scrot` (Ubuntu) or `sudo dnf install scrot` (Fedora)
  • Permission denied: `chmod +x *.sh`
  • Service not starting: Check logs at `~/RemoteControlSystem/logs/server.log`
  • Systemd service fails: Check `sudo journalctl -u remotecontrol`

macOS Issues

  • Screen Recording not working: Re-check System Settings → Privacy & Security → Screen Recording
  • Accessibility not working: Re-check System Settings → Privacy & Security → Accessibility
  • Homebrew not found: Run `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`
  • Python not found: Run `brew install python@3.11`
  • LaunchDaemon not loading: Check `launchctl list | grep remotecontrol` and verify plist syntax

General Issues

  • Can't connect: Verify server is running and firewall allows port 5000
  • Authentication failed: Reset password with `secure_server.ps1 -ResetPassword`
  • High latency: Check connection type (UDP is fastest, Relay is slowest)
  • Screen not updating: Check screen capture is enabled in config
  • Connection drops: Enable auto-reconnect in client config
