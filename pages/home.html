Quick Start (5 Minutes)

# 1. Clone the repository
git clone https://github.com/yourusername/remote-control-system.git
cd remote-control-system

# 2. Build the packages
.\scripts\build_separate_packages.ps1

# 3. Install Server (Controlled Computer - Run as Administrator)
.\deploy_server.ps1 -PackagePath .\deploy\RemoteControl_Server_v2.0.0.zip -RegisterService -ConfigureFirewall

# 4. Install Client (Your Computer)
.\deploy_client.ps1 -PackagePath .\deploy\RemoteControl_Client_v2.0.0.zip -ServerIP 192.168.1.100 -CreateShortcuts

# 5. Start Controlling!
# Double-click the desktop shortcut → Enter password → Click window → Control!
